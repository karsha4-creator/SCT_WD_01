SCT_WD_01 - Responsive Landing Page
Project Overview

This project is a Responsive Landing Page developed as part of the SkillCraft Technology Web Development Internship.

The landing page includes an interactive navigation menu that remains fixed at the top of the page and changes its appearance when the user scrolls. It also provides hover effects on menu items and adapts seamlessly to different screen sizes.

Features
Fixed Navigation Bar
Interactive Hover Effects
Scroll-Based Navigation Style Changes
Responsive Design for Mobile and Desktop
Smooth Scrolling Navigation
Modern User Interface
